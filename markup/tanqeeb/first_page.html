    Frontend Developer

    Remote - Egypt - Cairo · 6 hours ago
    Telecom & Technology
    EdfaPay
    Egypt - Cairo
    <p>Job Overview</p><p>We are seeking an experienced and passionate Frontend Developer to join our growing engineering team in Cairo, Egypt. In this role, you will be responsible for building high-quality, scalable, and responsive web applications that deliver exceptional user experiences. You will collaborate closely with UI/UX designers, backend engineers, and product managers to translate complex design concepts and requirements into clean, performant, and maintainable frontend code.<br>&nbsp;</p><p>Key Responsibilities</p><ul><li>Architect, build, and maintain modern, responsive, and intuitive web applications using advanced frontend technologies.</li><li>Collaborate with product managers and UI/UX designers to convert wireframes and design mockups into pixel-perfect user interfaces.</li><li>Integrate frontend applications seamlessly with backend RESTful APIs and WebSockets.</li><li>Optimize web applications for maximum speed, scalability, and cross-browser/cross-device compatibility.</li><li>Establish state management architecture and write modular, testable, and reusable code components.</li><li>Participate in code reviews, enforce coding standards, and mentor junior and mid-level developers.</li><li>Troubleshoot, debug, and resolve complex performance bottlenecks and production issues.<br>&nbsp;</li></ul><p>Qualifications &amp; Requirements</p><ul><li>Bachelor's degree in Computer Science, Software Engineering, or a related technical discipline.</li><li>5 to 7 years of hands-on professional experience in frontend web development.</li><li>Strong command of HTML5, CSS3, JavaScript (ES6+), and TypeScript.</li><li>Proficient experience with modern frontend frameworks and libraries such as React.js, Angular, or Vue.js.</li><li>Solid understanding of state management patterns and libraries (e.g., Redux, Context API, NgRx, or Vuex).</li><li>Expertise in CSS frameworks and preprocessors like Tailwind CSS, Sass, or SCSS.</li><li>Experience with frontend build tools, module bundlers, and package managers (Webpack, Vite, npm, Yarn).</li><li>Proficiency with Git version control and collaborative workflows (GitHub/GitLab).<br>&nbsp;</li></ul><p>Required Skills</p><ul><li>Strong analytical and problem-solving skills with high attention to detail.</li><li>Solid understanding of web performance optimization and SEO best practices.</li><li>Excellent communication and interpersonal skills to work effectively in an Agile/Scrum environment.</li><li>Familiarity with automated testing frameworks (Jest, React Testing Library, Cypress) is a plus.<br>&nbsp;</li></ul><p>Benefits &amp; Perks</p><ul><li>Competitive salary package aligned with experience and industry standards.</li><li>Comprehensive health and medical insurance coverage.</li><li>Opportunities for professional growth and continuous learning.</li><li>Dynamic, inclusive, and collaborative work environment in Cairo.</li><li>Flexible working hours and hybrid work arrangements.</li></ul>

بنية إدارة الحالة وكتابة مكونات كود معيارية وقابلة للاختبار وإعادة الاستخدام.</li><li>المشاركة في مراجعات الكود، وفرض معايير البرمجة، وتوجيه المطورين المبتدئين ومتوسطي المستوى.</li><li>استكشاف الأخطاء CSS أو Sass أو SCSS.</li><li>خبرة في أدوات بناء الواجهة الأمامية، ومجمعات الوحدات، ومديري الحزم (Webpack، Vite، npm، Yarn).</li><li>إتقان نظام التحكم في الإصدارات Git وسير العمل التعاوني (GitHub/GitLab).<br>&nbsp;</li></ul><p>المهارات المطلوبة</p><ul><li>مهارات تحليلية وحل مشكلات قوية مع اهتمام كبير بالتفاصيل.</li><li>فهم قوي لتحسين أداء الويب وأفضل ممارسات تحسين محركات البحث (SEO).</li><li>مهارات تواصل وشخصية ممتازة للعمل بفعالية في بيئة عمل مرنة (Agile/Scrum).</li><li>الإلمام بأطر الاختبار الآلي (Jest، React Testing Library، Cypress) يعتبر ميزة إضافية.<br>&nbsp;</li></ul><p>المزايا والحوافز</p><ul><li>حزمة رواتب تنافسية تتماشى مع الخبرة ومعايير الصناعة.</li><li>تغطية تأمين صحي وطبي شاملة.</li><li>فرص للنمو المهني والتعلم المستمر.</li><li>بيئة عمل ديناميكية وشاملة وتعاونية في القاهرة.</li><li>ساعات عمل مرنة وترتيبات عمل هجينة.</li></ul>
